My top three… Reel template

Listicle hook: 'my top three' items. Best for: Restaurants, hotels.

Hook (first 1–2 seconds)

“My top three things to order here.”

Shot list

  1. Item 3
  2. Item 2
  3. Item 1 (best)
  4. Storefront

Script skeleton

[Text] #3 … #2 … #1 → [Text] What's yours?

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: numbered-list template.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

bouncy pop, countdown energy, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
