Tonight's special Reel template

Same-day special with portion count. Best for: Restaurants.

Real-world example: a public Instagram post (Braise Restaurant; photo post). View post on Instagram (credit: the account owner).

Hook (first 1–2 seconds)

“Only [N] of these tonight.”

Shot list

  1. Special plated
  2. Close-up texture
  3. Chef holds it up
  4. Countdown sticker

Script skeleton

[Text] Tonight only · [N] portions → [VO] what's in it → [Text] Until they're gone

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: countdown.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

10-second catchy jingle, punchy, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
