Format 08 · Drive orders & bookings

Before & after Reel template

Raw ingredient to finished plate / transformation reveal. Best for: Restaurants, detailers, salons.

Hook (first 1–2 seconds)

“From this… to this.”

Shot list

  1. Raw ingredient / before state
  2. Mid-process
  3. Swipe transition
  4. Finished reveal

Script skeleton

[Text] Before → [transition on beat] → [Text] After · Book / order link in bio

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: swipe-transition.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

building synth riser with a drop, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
