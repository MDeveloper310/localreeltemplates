Behind-the-scenes prep Reel template

Film morning prep / setup before opening. Best for: Restaurants, bakeries.

Real-world example: a public Instagram post (Wandering Vine, KC restaurant). View post on Instagram (credit: the account owner).

Hook (first 1–2 seconds)

“6:45 a.m. Nobody sees this part.”

Shot list

  1. Lights on / door unlock
  2. Hands on prep list
  3. Knife work macro
  4. Ovens / burners firing
  5. Wide of set room, open sign

Script skeleton

[Text] What happens before we open → [VO] Every day starts here… → [Text] Doors open at 11. Come hungry.

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: beat-synced cut.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

upbeat acoustic funk, warm morning energy, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
