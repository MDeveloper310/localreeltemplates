POV kitchen rush Reel template

Ticket printer → plating → pass → dining room. Best for: Restaurants.

Hook (first 1–2 seconds)

“POV: it's Friday night at the pass.”

Shot list

  1. Ticket printer
  2. Pans firing
  3. Plating
  4. Pass bell
  5. Dining room

Script skeleton

[POV text] → fast cuts → [Text] Come see it live

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: POV text template.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

fast intense percussion, kitchen chaos, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
