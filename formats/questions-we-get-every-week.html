Questions we get every week Reel template

Answer recurring guest questions (source suggests carousel; adaptable to Reel). Best for: Restaurants, service businesses.

Hook (first 1–2 seconds)

“Questions we get every single week.”

Shot list

  1. Staffer to camera
  2. Q on screen
  3. Quick answer
  4. Next Q

Script skeleton

[Text] Q1 … A1 → Q2 … A2 → [Text] Got another? Comment it.

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: auto-captions.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

light ukulele, conversational, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
