Guest photo/UGC share Reel template

Share guest content with their OK. Best for: Any.

Hook (first 1–2 seconds)

“You made this. We had to share.”

Shot list

  1. Guest clip (with permission)
  2. Credit handle on screen
  3. Thank-you card

Script skeleton

[Text] Shot by @guest → [Text] Tag us to be featured

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: frame template.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

feel-good acoustic, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending

Check Suno's current terms for commercial use.
