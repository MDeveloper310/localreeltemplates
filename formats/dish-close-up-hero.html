Dish close-up hero Reel template

Extreme close-up/slow-mo of cheese pull, sauce, yolk. Best for: Restaurants, cafes.

Hook (first 1–2 seconds)

“Wait for it…”

Shot list

  1. Locked-off plate, shallow focus
  2. Slow push-in
  3. The pull / pour / cut in slow-mo
  4. Final hero frame with name + price

Script skeleton

[Text] Our most-ordered dish → [no VO, let it breathe] → [Text] Dish name · Where to find us

CapCut steps

  1. Import clips in shot order; set canvas to 9:16.
  2. Apply the edit idea: speed-ramp.
  3. Add on-screen text for the hook in the first second; run Auto captions.
  4. Add your music (Suno track or in-app audio); trim to the beat.
  5. Export 1080p; add a cover frame with the hook text.

Suno prompt idea

lo-fi hip hop, mellow, warm vinyl, instrumental, 15–30 seconds, clean intro, no vocals, loopable ending
